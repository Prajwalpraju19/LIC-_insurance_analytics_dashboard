# LIC Insurance Analytics Dashboard

## 📊 Project Overview

The **LIC Insurance Analytics Dashboard** is an end-to-end business intelligence project developed to analyze insurance data and generate meaningful business insights.

The project analyzes **customers, agents, policies, policy sales, claims, and premium performance** using Excel, MySQL, SQL, and Power BI.

## 🎯 Project Objectives

* Analyze insurance policy performance
* Understand premium generation
* Analyze customer trends
* Identify top-performing agents
* Analyze claim status and distribution
* Understand policy distribution by payment mode
* Support data-driven business decision-making

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning and preparation
* **MySQL** – Database management
* **SQL** – Data querying and business analysis
* **Power BI** – Interactive dashboards and visualization

## 📁 Datasets

The project contains:

* Customers
* Agents
* Policies
* Policy Sales
* Claims

```text

    ↓
Interactive Dashboard
```

## 📈 Dashboard Features

The Power BI dashboard includes:

* KPI cards for key business metrics
* Customer analysis
* Policy analysis
* Premium analysis
* Claims analysis
* agent analysis
* sales analysis
* Customer age distribution by city
* Premium by claim status
* Policy distribution by payment mode
* Claim status distribution by gender
* Interactive slicers and filters
* Revenue generated per term

## 💡 Business Insights

The dashboard helps identify:

* High-performing agents
* Premium generation patterns
* Policy performance
* Claim status distribution
* Customer trends across cities
* Payment mode distribution
* Areas that can support better business decisions
